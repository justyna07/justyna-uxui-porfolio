Case study 3 / AI product · Analytics

A performance report that checks its own claims.

A human-reviewed reporting experience that links every numeric statement to data before a client-facing summary can be approved.

RoleUX / AI workflow design
AudienceAccount managers
PatternsClaim checks · Approval gates · Source integrity
01 / Context

Fluent summaries are not always accurate.

Account managers needed more than another dashboard. Early AI-generated summaries were quick to draft but could introduce statements that the underlying paid-media data did not support.

Reviewing every sentence manually erased much of the speed benefit.

Product problem: Help managers communicate performance clearly while retaining full control over factual claims and client delivery.

02 / Constraints

Client-facing claims demand traceability.

  • Data sources can be delayed or unavailable.
  • Missing data must not be mistaken for a zero or stable result.
  • Managers need to edit voice and context without bypassing verification.
  • Approval and send should be separate, intentional actions.
03 / Decision

Draft, verify, edit, approve.

The selected design pairs an editable narrative with source metrics and a claim check. Unsupported statements block approval. Sending is a separate operational step not present in this offline demo.

Earlier concept

AI draft above a KPI table; user manually cross-checks every claim.

Selected concept

Source-backed KPI view, claim flags, editable summary, approval gate and named reviewer.

04 / Prototype

Test the review gate.

Choose a sample scenario, adjust the draft and run the claim check. The demo contains illustrative figures only and cannot send email.

Weekly report · review screenIllustrative figures · no email capability
05 / Outcome

Designed around trustworthy output.

Success metrics include minutes per report, proportion of drafts edited, unsupported claims caught before approval and unsupported claims sent (target: zero). Published pilot metrics are excluded until independently verified.

A structured workflow also creates clearer ownership: models assist with drafting, while people remain responsible for final client communication.

06 / Reflection

Improve the feedback loop.

Capture edit reasons such as inaccurate claims, missing context and tone changes. Validate clarity with actual report recipients, not only internal managers. Instrument source outages so the system refuses to draft rather than presenting incomplete information as complete.
